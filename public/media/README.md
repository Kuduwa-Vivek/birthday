# Media folder

Place your personal media files here. The site works without them — placeholders appear if a file is missing.

## Suggested files

| File | Purpose |
|------|---------|
| `photo1.jpg` … `photo4.jpg` | Memory journey photos |
| `final-photo.jpg` | Final cinematic photo |
| `video1.mp4` | Memory video |
| `video2.mp4` | Optional second video |
| `birthday-music.mp3` | Soft looping background music |
| `easter-photo.jpg` | Easter egg funny photo |
| `easter-video.mp4` | Easter egg funny video |

Update paths in `src/config/birthdayConfig.js` if you use different filenames.
